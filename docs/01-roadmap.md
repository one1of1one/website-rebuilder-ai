# Reforge AI Roadmap

## v1.0 Core Rebuilder Engine

- crawl public pages, sitemap, robots, and same-domain links
- detect technologies and assets
- generate reports and ZIP exports
- support stable rebuild modes and output types

## v2.0 AI Refactor Engine

- improve rule-based refactoring
- extract more reusable components
- generate better docs and project structure
- add stronger quality scores and cleanup passes

## v3.0 Visual + Component AI

- add visual understanding
- improve layout detection
- compare DOM and visual regions
- generate better section/component boundaries

## v4.0 Framework Migration Engine

- migrate between output targets
- support deeper scaffold generation
- improve mapping from legacy sites to modern stacks

## v5.0 Enterprise SaaS

- project history at scale
- team workspaces
- deployment center
- plugin ecosystem
- provider management
- observability and audit logs
- billing and plans

Roadmap rules:

- keep the core engine stable at every step
- never couple the UI to a single engine implementation
- prefer additive changes over rewrites
- preserve backwards compatibility for project files and reports
