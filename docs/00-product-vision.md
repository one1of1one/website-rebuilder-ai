# Reforge AI Product Vision

Reforge AI is an AI website reverse engineering and modernization platform.
Its job is to transform any public website into a clean, maintainable,
developer-friendly project.

It is not a website downloader.

The product should:

- crawl public websites responsibly
- detect technologies and runtime hints
- analyze DOM, layout, components, assets, SEO, accessibility, and performance
- rebuild source into structured output formats
- support editing, chat-based refinement, exports, and deployment workflows

Core product principles:

- Deterministic first, AI-assisted second
- Repeatable rebuilds with transparent rules
- Safe handling of user-owned or authorized websites only
- Modular engine design so each subsystem can evolve independently

Target user:

- developers
- agencies
- QA and migration teams
- technical founders
- site owners modernizing older websites

Primary promise:

- Analyze. Reverse Engineer. Rebuild.

Success looks like:

- a user pastes a URL
- Reforge AI maps the site structure
- the engine identifies pages, routes, components, and assets
- the output becomes a clean project with reports and export options
- the user can inspect, edit, refine, and deploy the result
